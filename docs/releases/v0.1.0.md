The first preview of Jobiza: your research library, literature reviews and writing, with Claude, on your own computer and phone.

## Downloads

| File | For |
|---|---|
| `Jobiza-Setup-0.1.0.exe` | Windows 10 or 11, 64-bit |
| `Jobiza-0.1.0-android-arm64*.apk` | Android 8 or newer, 64-bit (almost every phone from 2017 on) |
| `SHA256SUMS.txt` | Checksums to confirm the downloads are intact |

You need an Anthropic API key (from console.anthropic.com). Claude features are billed to it; searching and organising your library are free and run on your device.

## Install

**Windows:** run `Jobiza-Setup-0.1.0.exe`. The installer isn't code-signed yet, so SmartScreen warns you the first time: choose *More info*, then *Run anyway*. When Windows asks whether Jobiza may use the network, allow private networks (that's how it syncs with your phone).

**Android:** open the `.apk` on the phone and allow installs from your browser or file manager when asked. The first launch takes about 30 seconds to set up; after that it opens in a few seconds.

**Then:** open *Settings*, add your API key and choose a model. To keep the computer and phone in step, open *Settings → Devices and sync* on the computer, choose *Pair a new device*, and scan the code from the phone.

## What's in it

- **Library**: add PDFs, DOIs and links (or share them to Jobiza from other Android apps); ask questions and get answers that cite the page.
- **Literature reviews**: Jobiza searches OpenAlex, Semantic Scholar, arXiv and PubMed, screens what it finds, reads the included studies, fills a comparison table and writes a cited synthesis, with a PRISMA log. Read any paper it finds right in the review.
- **Writing**: an editor with live citations in six styles, a claim checker that verifies quotes against your sources, and export to Word, PDF and LaTeX.
- **Research proposals**: describe your idea, adjust Claude's plan, and get each section written from your library with real citations.
- **Your data stays yours**: each device keeps its own complete library and works offline; paired devices sync on your Wi-Fi with end-to-end encryption.

## Known limitations

- This is a preview. The Windows installer is unsigned. The Android APK is a debug build unless it's named without `-debug`, and a debug build can't be updated in place by a later release: uninstall it first (after syncing to a computer, to keep your library).
- Sync works on the same Wi-Fi network only.
- Android may pause Jobiza in the background; a literature-review step that gets interrupted can be run again.
- No macOS, Linux desktop or iOS builds yet.
