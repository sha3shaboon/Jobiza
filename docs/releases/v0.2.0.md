Jobiza now updates itself.

## New

- **Automatic updates.** Jobiza checks this page for new versions every few hours. On Windows, a new version downloads in the background and installs the next time you close Jobiza; a notification and a banner in the app offer *Restart and update* if you'd rather do it now. On Android, it downloads on Wi-Fi and Android asks you to confirm the install. Your library is kept either way.
- **Settings → Updates**: your version, *Update automatically* (on by default), *Check for updates*, and what's new in the next version. On Windows there's also *Help → Check for updates…*.

## Installing this version

- **Windows:** run `Jobiza-Setup-0.2.0.exe` once over your current version. Every version after this one arrives automatically.
- **Android:** if the file name ends in `-debug.apk`, this build can't update itself yet (see the 0.1.0 notes). Once releases are signed, uninstall the old app once and install the signed one; after that, updates are automatic. Pair with your computer first so your library is kept.
